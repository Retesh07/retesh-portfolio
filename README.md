## 🌐 Overview & Highlights

A modern, high-performance, kinetic typography developer portfolio built with **Next.js (App Router), React 18, TypeScript, Tailwind CSS, and Framer Motion**.

* 🎨 **Kinetic Typography & Mouse Parallax**: Interactive 3D tilt effects, ambient cursor lighting, and glassmorphic card elements.
* 🤖 **AI & Systems Showcase**: Features flagship projects including **DocMind AI** (Agentic RAG Platform) and **YatrAI** (AI-Powered Indian Travel Itinerary Planner).
* ⚡ **Performance & UX**: Dark mode design system, smooth scroll reveals, responsive 3D cards, and micro-interactions.

## 🚀 Getting Started Locally

```bash
# Clone repository
git clone https://github.com/Retesh07/retesh-portfolio.git
cd retesh-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.
